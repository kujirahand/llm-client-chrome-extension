# プライバシーポリシー

## Ollama Client for Chrome Extension プライバシーポリシー

最終更新日: 2025年7月24日

### 1. データの収集と使用

この拡張機能（Ollama Client for Chrome Extension）は、以下の原則に基づいてユーザーのプライバシーを保護します：

- **ローカル処理**: すべてのデータ処理はユーザーのローカル環境で行われます
- **データの外部送信**: ユーザーが入力したデータは、ユーザーが指定したOllama APIのURL以外には送信されません
- **第三者への共有**: 収集したデータを第三者と共有することはありません

### 2. 収集する情報

当拡張機能は以下の情報を処理します：

- **チャット入力**: ユーザーがチャット画面に入力したテキスト
- **設定情報**: Ollama APIのホストURL、使用モデル、システムプロンプト、言語設定
- **ウェブページコンテンツ**: 拡張機能を起動した際に閲覧していたウェブサイトのコンテンツ（ユーザーの同意がある場合のみ）
- **チャット履歴**: ローカルストレージに保存されるチャット履歴

### 3. データの保存と処理

- **ローカル保存**: すべてのデータはユーザーのブラウザ内のローカルストレージに保存されます
- **外部サーバー**: 開発者（kujirahand.com）のサーバーにデータを送信することはありません
- **Ollama API**: ユーザーが指定したOllama APIエンドポイントにのみデータを送信します

### 4. ウェブページコンテンツの活用

この拡張機能は、より良いチャット体験を提供するために：

- 拡張機能を起動した際に閲覧していたウェブページのコンテンツを読み取る場合があります
- このコンテンツは、チャットの文脈として活用されます
- ウェブページコンテンツも、ユーザーが指定したOllama API以外には送信されません

### 5. セキュリティ

- すべての通信は可能な限り暗号化されます
- ユーザーのデータを外部の第三者に送信することはありません
- Chrome拡張機能のセキュリティ機能を活用してデータを保護します

### 6. ユーザーの権利

ユーザーは以下の権利を有します：

- **データの削除**: 拡張機能の設定からチャット履歴を削除できます
- **設定の変更**: いつでもOllama APIの接続先を変更できます
- **拡張機能の削除**: Chromeの設定から拡張機能を完全に削除できます

### 7. 開発者の誓約

開発者（kujirahand.com）は、以下を誓約します：

- ユーザーのプライバシーを最優先に考慮します
- ユーザーの入力データを、ユーザーが指定したOllama API以外には送信しません
- 透明性を保ち、プライバシーポリシーに変更がある場合は事前に通知します
