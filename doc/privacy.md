# Privacy Policy

## Privacy Policy for Ollama Client for Chrome Extension

Last updated: July 24, 2025

### 1. Data Collection and Usage

This extension (Ollama Client for Chrome Extension) protects user privacy based on the following principles:

- **Local Processing**: All data processing occurs locally in the user's environment
- **External Data Transmission**: User input data is only sent to the Ollama API URL specified by the user
- **Third-party Sharing**: We do not share collected data with third parties

### 2. Information We Process

This extension processes the following information:

- **Chat Input**: Text entered by users in the chat interface
- **Settings**: Ollama API host URL, model selection, system prompts, language preferences
- **Web Page Content**: Content from websites viewed when the extension is activated (only with user consent)
- **Chat History**: Chat history stored in local storage

### 3. Data Storage and Processing

- **Local Storage**: All data is stored in the user's browser local storage
- **External Servers**: No data is sent to the developer's (kujirahand.com) servers
- **Ollama API**: Data is only sent to the Ollama API endpoint specified by the user

### 4. Web Page Content Utilization

To provide a better chat experience, this extension:

- May read content from web pages viewed when the extension is activated
- Uses this content as context for chat conversations
- Does not send web page content to any destination other than the user-specified Ollama API

### 5. Security

- All communications are encrypted whenever possible
- User data is never transmitted to external third parties
- Chrome extension security features are utilized to protect data

### 6. User Rights

Users have the following rights:

- **Data Deletion**: Delete chat history from extension settings
- **Settings Modification**: Change Ollama API connection settings at any time
- **Extension Removal**: Completely remove the extension from Chrome settings

### 7. Developer Commitment

The developer (kujirahand.com) commits to:

- Prioritizing user privacy above all else
- Not sending user input data to any destination other than the user-specified Ollama API
- Maintaining transparency and providing advance notice of any privacy policy changes

### 8. Contact

For privacy-related inquiries, please contact:
